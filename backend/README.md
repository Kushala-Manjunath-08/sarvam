# Backend — LEGACYOS

> Human Knowledge Preservation System
> **Status: Placeholder — Implementation begins in Phase 3**

---

## Overview

This directory will contain the Python FastAPI backend for LEGACYOS.

The backend is responsible for:
- Exposing a RESTful API consumed by the Next.js frontend.
- Managing user authentication and authorisation (JWT).
- Receiving and validating uploaded media files.
- Orchestrating the AI processing pipeline (transcription → extraction → embedding).
- Interfacing with PostgreSQL, ChromaDB, and external AI services (Whisper, Groq).

## Planned Environment Variables

Copy `frontend/.env.example` to `backend/.env` and fill in:

```
DATABASE_URL=postgresql://user:password@localhost:5432/legacyos
GROQ_API_KEY=your_groq_api_key_here
CHROMADB_HOST=localhost
CHROMADB_PORT=8000
NEO4J_URI=bolt://localhost:7687
NEO4J_USER=neo4j
NEO4J_PASSWORD=your_neo4j_password_here
JWT_SECRET_KEY=your_jwt_secret_key_here
STORAGE_BUCKET=your_storage_bucket_name
```

## Setup Instructions (Phase 3+)

```bash
# Navigate to the backend directory
cd backend

# Create a virtual environment
python -m venv .venv

# Activate the virtual environment (Windows)
.venv\Scripts\activate

# Activate the virtual environment (macOS/Linux)
source .venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run database migrations
alembic upgrade head

# Start the development server
uvicorn app.main:app --reload --port 8000
```

The API will be available at `http://localhost:8000`.
API documentation (auto-generated by FastAPI) will be at `http://localhost:8000/docs`.
